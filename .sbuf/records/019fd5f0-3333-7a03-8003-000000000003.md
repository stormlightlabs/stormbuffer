`stormbuffer invoke` is the stable native agent protocol and remains at version 1 until the initial release. It accepts one bounded JSON request on stdin, emits JSON only on stdout, sends diagnostics only to stderr, never prompts, rejects arbitrary filesystem paths, and requires explicit scope and mutation permissions.

The CLI, JSON invocation, MCP, and HTTP server are adapters over `stormbuffer-core`; none may parse or mutate canonical records, edit SQLite, implement ranking, or duplicate policy independently. `stormbuffer`, `stormbuf`, and `sbuf` are equivalent public executable names, but protocol behavior has a deliberately smaller surface than the interactive CLI.
