Project memory lives in the nearest `.sbuf/`. It is private and ignored by Git by default; sharing must be an explicit choice made with `stormbuffer --project init --shared`.

A shared store commits only `store.toml`, its ignore rules, and canonical Markdown records. Databases, FTS and vector projections, embeddings, downloaded models, locks, temporary files, and logs remain ignored because they are machine-local and rebuildable. Global data and model caches use platform directories and must never be copied into a project store.
