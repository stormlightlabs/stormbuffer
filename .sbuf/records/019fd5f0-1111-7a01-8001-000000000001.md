Stormbuffer can grow beyond baseline FTS, embeddings, and reciprocal-rank fusion when its evaluation corpus reveals a repeatable weakness. Choose the next layer by failure type and retain it only when the checked metrics improve without breaking scope, lifecycle, or provenance guarantees.

- Add a local reranker when the relevant memory is consistently retrieved but ordered below distractors.
- Add contextual indexing when short or ambiguous chunks lose the document context needed for retrieval.
- Add entity or relationship links when multi-hop questions repeatedly require facts spread across records.
- Add temporal or contradiction handling when supersession alone cannot represent changing claims clearly.
- Add consolidation assistance when duplicate candidate memories become a measured review burden.

Each capability should remain a replaceable projection over canonical Markdown. Record the motivating evaluation cases and compare the new layer with the lexical, vector, and hybrid baselines before making it part of the default pipeline.
