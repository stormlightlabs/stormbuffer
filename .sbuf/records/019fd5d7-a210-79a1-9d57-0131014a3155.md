Embedding dimensions and preprocessing are structural index properties. A model change must build and backfill a new versioned vector table, validate it, and only then switch the active-table pointer; it must never overwrite the active vector index in place.

The embedding fingerprint includes the model and tokenizer artifact hashes, dimensions, token limit, pooling, normalization, and preprocessing version. A mismatch makes the old projection stale and rebuildable rather than allowing vectors from incompatible embedding spaces to mix.
