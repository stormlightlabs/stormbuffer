The default semantic model is `sentence-transformers/all-MiniLM-L6-v2` with 384-dimensional output. Use pinned `fastembed` as the Rust integration over ONNX Runtime rather than assembling tokenization, pooling, and inference directly with `ort`; keep the project-owned `Embedder` boundary so the dependency can be replaced later.

`stormbuffer init` for the global store acquires verified model artifacts in the platform cache at `stormbuffer/models` under the operating system cache root. It does not use the app-data or XDG configuration directory. Project initialization never downloads a private copy; project semantic retrieval reuses the verified global model cache. Stormbuffer owns the artifact manifest, hashes, resumable acquisition, and cache locking.
